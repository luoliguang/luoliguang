# 👋 Hi, I'm luoliguang

你好，我是工程服装跟单客服，目前在工厂担任供货商客服角色。日常工作中，我发现客户频繁索要服装实物图片，传统聊天窗口发送图片既繁琐又重复。于是我结合新技术和 AI，开发了 [fangdu](https://github.com/luoliguang/fangdu) 项目，旨在简化客户获取实物图的流程，让沟通更高效。

## 🚩 关于 fangdu 项目
> fangdu是一个在线服装实物图展示网站，作为工厂跟单客服，每天重复性的给客户发图片真的麻烦。

- **项目简介**：在线展示服装实物图片，减少重复劳动，提升客服效率。
- **技术栈**：Vue (45.8%)、JavaScript (38.6%)、Shell、PowerShell、CSS 等。
- **应用场景**：用于跟单客服向客户快速展示工厂实拍服装图片。
