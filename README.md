### [fangdu · 服装实物图展示网站](https://github.com/luoliguang/fangdu)

> 每天重复给客户发图片，繁琐、低效、浪费时间。

于是我做了这个——客户自己打开链接就能看到所有实拍图，不用再等我一张张发。

- **技术栈**：Vue / JavaScript / CSS
- **解决的问题**：减少客服重复劳动，让沟通回归真正重要的事

### AI知识库系统

> 新员工入职、客户反复问同样的问题——信息散落在聊天记录里，找不到、说不清。

用Docker部署开源知识库项目，把工厂的业务知识整理进去，
让常见问题有地方查、让AI能直接回答。

- **技术栈**：Docker / 开源RAG项目
- **解决的问题**：把经验沉淀下来，不再靠人传人

### WPS自动化工具 / AI报价辅助
